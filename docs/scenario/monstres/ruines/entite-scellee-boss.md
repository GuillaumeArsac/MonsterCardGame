# L'Entité Scellée — Boss Final

Le boss final des Ruines Oubliées. La source de tous les monstres.

| Champ | Valeur |
|---|---|
| **Zone** | Les Ruines Oubliées |
| **Type** | Boss Final |
| **Difficulté** | ★★★ |
| **Mécanique associée** | Risque/récompense — synthèse de toutes les mécaniques rencontrées |
| **Rareté des matériaux** | Unique |

## Rôle narratif

La confrontation finale. Le joueur sait maintenant la vérité — chaque carte qu'il a forgée
a contribué à libérer ce qu'il combat.
Pas un monstre ordinaire : une conscience ancienne fragmentée, drainée et réveillée.

## Notes design

- Le boss final doit se sentir différent de tous les autres — pas juste plus difficile
- Ses cartes uniques devraient porter la mémoire de toutes les zones traversées
- La question narrative non résolue : est-elle malveillante ou juste aveugle ?
  → La réponse devrait influencer les effets de ses cartes Uniques
