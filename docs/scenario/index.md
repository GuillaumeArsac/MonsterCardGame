# Scénario — Monster Card Game

Index central de la documentation narrative. Chaque zone, monstre, PNJ et carte a sa fiche ici.

## Structure narrative

**Acte 1 — L'Urgence**
Prologue (La Cité) → Les Plaines Libres → premier boss

**Acte 2 — La Traversée**
4 zones libres dans n'importe quel ordre :
Les Marais · La Forêt · Les Montagnes · L'Archipel

**Acte 3 — La Révélation**
Les Ruines Oubliées → boss final → épilogue
