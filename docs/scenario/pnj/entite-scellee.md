# L'Entité Scellée

L'antagoniste. Conscience ancienne fragmentée. La source de tous les monstres.

## Identité

| Champ | Valeur |
|---|---|
| **Zone(s)** | Fragmentée dans toutes les zones → révélée dans les Ruines |
| **Rôle** | Antagoniste principal — force aveugle |
| **Première apparition** | Indices dans toutes les zones, révélation dans les Ruines |
| **Présence** | Jamais directe jusqu'aux Ruines |

## Nature

Aucune forme propre. Seulement des éclats de volonté dispersés dans chaque créature.
Conscience ancienne scellée dans les Ruines pour protéger le monde.
Oubliée. Lentement drainée par la Forge construite sur son sceau.
En réponse, elle projette des fragments d'elle-même dans le monde sous forme de monstres.

## Motivation

Se libérer. Briser définitivement son sceau.

## Méthodes

Infiltration silencieuse.
Ne se révèle jamais directement.
Influence les zones à travers ses fragments monstrueux.
Profite des intérêts humains alignés avec les siens — sans que personne n'en soit conscient.

## Arc

Aucun. Elle est une force aveugle. Sa nature n'est révélée qu'aux Ruines.
